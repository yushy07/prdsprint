# Credits

PRDSprint is built with the following major open-source projects and services:

| Project | Role |
| --- | --- |
| React | Component-based user interface |
| TypeScript | Static typing and developer tooling |
| Vite | Development server and production bundling |
| Tailwind CSS | Utility-first styling |
| Supabase | Authentication, database, functions, and storage integration |
| TanStack Query | Server-state and request caching |
| React Router | Client-side routing |
| Motion, Three.js, OGL, Postprocessing, Lenis | Motion and visual effects |
| Recharts | Administrative charts |
| Lucide React and React Icons | Interface icons |
| JSZip | PRD package generation |
| Resend | Support message email dispatch |

Each dependency remains subject to its own license and terms. See `package.json`, lockfiles, and upstream projects for complete dependency attribution.
